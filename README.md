# Lincoln Electric Holdings (lincoln-electric-holdings)

Lincoln Electric Holdings is a global manufacturer of arc welding products, robotic welding systems, plasma and oxyfuel cutting equipment, and brazing and soldering alloys. The company also offers connected welding solutions and equipment monitoring software for industrial environments.
